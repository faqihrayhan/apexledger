Built like a vault, runs like a tool.

Database-enforced double entry

Balance validation, posting, reversals, and period closes are PL/pgSQL functions. The engine refuses unbalanced entries at the storage layer — no application bug can corrupt the books.

Immutable ledger

UPDATE and DELETE privileges on journal tables are revoked at the database level. Corrections happen through reversing entries, preserving the full audit trail forever.

Optional AI assistant

Bring your own key (OpenAI) or run a local model (Ollama). The assistant records transactions through the same secured RPCs — it can never leave your entity or bypass role checks.

Fast, dense UI

A dark, keyboard-first interface with virtualized journals for thousands of rows, live debit/credit balance indicators, and a trial balance that proves itself.

One-command setup

apexledger init prepares the container, database, and migrations. A first-boot wizard creates your entity, admin, and fiscal calendar — no manual SQL.

Auto-backup before anything

apexledger backup dumps a timestamped, gzipped snapshot. Updates are opt-in and never install themselves.

Security model

Row-Level Security

Every table is entity-scoped. JWT claims are injected into the PostgreSQL session so policies evaluate the caller without trusting the application.

Dual-layer defense

Read endpoints filter by entity again at the application layer. Isolation holds even if a connection bypasses RLS.

Roles in the engine

Only finance roles can create or post journals — checked inside the database function, not just the API.

Install

Community edition runs entirely on one machine with Docker and Python 3.11+.

git clone https://github.com/faqihrayhan/apexledger.git
cd apexledger/backend
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env

python cli.py init     # container + database + migrations
python cli.py serve    # API on :8000 — open http://localhost:8000/docs
